# Architecture Decision Records

Record significant decisions as numbered files such as `0001-offline-first.md`.

Each record should contain:

- Status
- Context
- Decision
- Consequences
- Alternatives considered

Implementation-language and tooling references in ADRs 0001–0017 describe their historical implementation. [ADR 0018](0018-native-swift-migration.md) supersedes Flutter/Dart/sqflite tooling with Swift/SwiftUI/system SQLite while preserving approved domain and storage contracts. Use [the native architecture](../ARCHITECTURE.md) and [testing guide](../TESTING.md) for current commands.
